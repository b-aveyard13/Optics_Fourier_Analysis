# Optics_Fourier_Analysis
Mini-project on Fourier analysis using an optical system, as part of undergrad work.
Used a 0.9mW 633nm laser and CCD camera in a 4-f optical system to reproduce the Abbe-Porter experiment.
The "Code" file contains the numerical model used to analyse the obtained laboratory images and produce various plots illustrating the correlations between image properties and the Abbe-Porter principle.
"Results" contains the resulting plots, figures, and grid image used to test the modelling system. "col_[number]" shows a line-out of the test grid, according to the number of pixels used as the filter size.
